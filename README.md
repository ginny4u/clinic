## 구조

| 자리 | 무엇 | 어디에 |
|---|---|---|
| 화면 | `26-2-final/index.html` (학생·선생님·학부모 화면 전부), `sw.js`, 아이콘, 매니페스트 | 이 저장소 → GitHub Pages |
| 서버 | Apps Script 프로젝트: `Code.gs`(로그인·저장·시트 입출력, 선생님 비밀번호) + `omr.gs`(무한선지·채점·리포트) | 저작권자의 구글 계정. **저장소에는 없다** |
| 데이터 | 구글 시트 탭 `students` `sets` `items` `subs` `checks` `parents` 등 | Apps Script가 붙어 있는 스프레드시트 |

화면 파일 안의 `CORE_ACTIONS`(공통 로직)는 Apps Script에도 같은 내용이 들어 있어서, 서버 주소를 비우면 예시 데이터로 미리보기가 열린다(`IS_DEMO`). 그래서 **화면만 복사해 가도 실제 학생·기록·비밀번호에는 닿지 못한다.** 그건 전부 서버와 시트에 있다.

## 전수하기 (다른 선생님에게 통째로 넘길 때)

받는 쪽이 자기 계정으로 따로 세워 쓰는 방식이다. 내 학생 데이터·서버·비밀번호는 전혀 섞이지 않는다.

### 내가 챙겨 줄 것 3가지
1. **이 저장소** — GitHub에서 Fork(받는 선생님 계정으로) 또는 Code → Download ZIP.
2. **`Code.gs`** — 내 Apps Script 편집기에서 열어 복사. 맨 위 `var ADMIN_PASSWORD = '…'`를 **비워서** 주거나 `'여기에 비밀번호'`로 바꿔서 준다(받는 쪽이 자기 것으로 넣는다).
3. **`omr.gs`** — 같은 편집기에서 복사. 그대로 줘도 된다(비밀번호 없음).

### 받는 쪽이 할 일 (30분)
1. **시트 만들기** — 구글 드라이브에서 새 스프레드시트. 이름은 아무거나.
2. **Apps Script 열기** — 시트 메뉴 확장 프로그램 → Apps Script. 기본 파일(코드.gs)에 `Code.gs` 내용을 붙여 넣고, 파일 ＋ → 스크립트 → 이름 `omr` → `omr.gs` 내용을 붙여 넣는다. 맨 위 `ADMIN_PASSWORD`에 자기 선생님 비밀번호(숫자)를 넣고 저장.
3. **탭 만들기** — 함수 목록에서 `setup` 선택 → 실행 (처음 한 번 권한 허용). 시트에 탭이 생긴다. 이어서 `omrCheck` 실행 → 로그에 이상 없음 확인.
4. **배포** — 배포 → 새 배포 → 유형 '웹 앱' → 실행 주체 **나**, 액세스 권한 **모든 사용자** → 배포. 나온 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사.
5. **화면에 서버 주소 넣기** — 저장소의 `26-2-final/index.html`에서 `var CLINIC_API_URL = '…'` 한 줄만 자기 URL로 바꾼다.
6. **GitHub Pages 켜기** — 저장소 Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save. 몇 분 뒤 `https://<아이디>.github.io/<저장소>/26-2-final/`로 열린다.
7. **학생 넣기** — 선생님 비밀번호로 들어가 학생 추가(학교·이름). 첫 비밀번호는 0000이고 학생이 첫 로그인 때 바꾼다.

### 나중에 서버를 고칠 때
Apps Script에서 파일을 고친 뒤 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 주소는 그대로 유지된다. 화면이 "서버가 예전 버전"이라고 하면 이 단계를 빠뜨린 것.

### 같이 쓰는 것
- 맞춤법 교정실(`ginny4u/orthography`)은 이 트래커 계정으로 로그인한다. 같이 넘길 때는 그쪽 README '서버 붙이기'대로 `orth.gs`를 이 Apps Script에 추가하면 된다. 트래커만 넘기면 그 단계는 필요 없다.
- 맥가이 연동 북마크(학생 평가 칸 채우기)는 화면 안에 들어 있어서 따로 할 일이 없다.
